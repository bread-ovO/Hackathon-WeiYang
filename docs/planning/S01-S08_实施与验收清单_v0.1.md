| S03-A06 | 联合：F02/L03/G02、Q03 | 真实分页来源断网、轮转/补采、提交确认丢失及请求在途撤权后恢复 | 从宿主最后提交检查点续传；未提交页不跳过；scope 变化后旧请求不提交；记录来源游标有效期及不可恢复覆盖缺口 |

## 10. 跨模块联合验收与完成边界

| 父需求 | 可先独立交付的范围 | 父需求最终验收还需 |
| --- | --- | --- |
| S01 | parser、转换、追溯与多类型合成样例 | 两个真实授权来源的共同信封及实际覆盖记录（F/L/G、D02/D03） |
| S02 | 真实表约束、迁移、命名仓储和四维持久化 | 条件/人工/自动决定实际写入与引用检查（V01/V05/H01），不能仅建表 |
| S03 | 分页事务、回执、CAS 与隔离故障恢复 | 真实连接器只在持久确认后继续及撤权行为（F02/L03/G02/Q03） |
| S04 | 事件和根作业唯一性、内容冲突拒绝 | 重复十次仅一次业务变更及人工纠正保护（A01/V05/H01） |
| S05 | 租约、有限重试和可控 handler 恢复 | 真实业务与 job.done 原子提交、模型取消/撤权（V05/A07/Q03/E05） |
| S06 | 有界检索、隔离、重建和合成召回报告 | A04 使用候选而非直接合并；Q05 删除联验；真实质量及试用性能另按 T02/T05 记录 |
| S07 | 时间、命名空间、映射与事实顺序 | 改期/迟到反证不破坏新计划，保护人工决定（A02/A04/V01/V05/H01） |
| S08 | 输入/队列/磁盘准入、恢复与诊断 DTO | 所有连接器/自动写入遵守准入，来源页能解释暂停恢复（U03）；资源预算与 T04/T05 联验 |

基础测试可以使用纯函数/可控 handler，但数据库约束、事务、索引和租约必须在真实 SQLite 上测。真实业务联验要走 application 的真实提交入口，不能直接插行构造“成功业务状态”。

必须覆盖的完整故障链可复用上述用例：整页接收到 ACK 丢失（S03-A02）；业务提交到进程退出（S04-A05/S05-A05）；撤回与人工完成竞争（S02-A04/S07-A03）；映射撤销与迟到计划（S07-A04/A06）；超额暂停到容量恢复（S08-A03/A05）。

## 11. 执行与证据记录

建议新增测试文件按 contracts、migration、ingestion、jobs、search、identity、capacity 分组。现有 scripts/test-storage.mjs 只打包一个入口，实施时扩展为明确列出的集成入口并汇总失败退出码，不能新增测试文件却未纳入 pnpm check。所有用例使用独立临时目录，结束时关闭所有连接/子进程再清理。
