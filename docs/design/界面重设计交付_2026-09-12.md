# 事项助手界面重设计

2026-09-12。已落地到 Electron renderer，并生成本地未签名应用。

## 界面结构

主导航使用“跟进、连接”，设置收至侧栏底部。项目作为轻量筛选入口。跟进页面以清单为主，选中后就地展开详情：下一步、完成条件、最初约定、最近进展。来源记录支持展开查看。应用与文件采用行式管理，逐项说明未来接入用途和未连接状态。

菜单与窗口共用中性灰底色；右侧白色工作区独立成 14px 圆角面板，上、右、下保留 8px 外边距，左侧由菜单留出间隔。内容在圆角内裁剪。使用 Kumo 语义色、蓝色主操作、轻边线与少量橙色定位提示；正文和主要控件以 14px 为基准。窗口使用原生隐藏标题栏，保留 macOS 窗口按钮。小于等于 900px 时详情采用单列，返回保留列表筛选。

## Kumo 组件与 skill

已接入 `@cloudflare/kumo@2.13.2`，使用真实 Button、Input、Badge、Dialog，图标使用 Phosphor。`ui/index.tsx` 封装应用默认按钮、输入、领域状态徽标、弹窗和工作区面板；保留原组件的交互能力。无 Tailwind 的现有工程加载 Kumo standalone 样式，再应用项目样式。受控弹窗补充关闭后的入口焦点恢复。

文档依据：[官方仓库](https://github.com/cloudflare/kumo)、[官方文档](https://kumo-ui.com)，以及安装版本的类型声明和 `kumo doc` CLI。可复用 skill 位于 `skills/kumo-desktop-ui/`，同时安装至 `~/.codex/skills/kumo-desktop-ui/`，可用 `$kumo-desktop-ui` 调用。它包含版本查询、组件封装、语义色、圆角工作区约定、可访问性和验证步骤。结构校验通过。

## 交互与真实能力

默认“示例体验”包含明确标注的虚构事项，可以筛选、搜索、切换项目、查看依据、添加示例事项、确认跟进和手动完成。人工完成不修改来源条件，可通过提示条撤销最近的状态操作。示例只驻留 renderer 内存，关闭窗口后清除，不写数据库、不触发任何外部业务操作。

“我的工作区”没有虚构项目和事项，显示未接入空态。连接页的四种接入方向均禁用连接操作并明确标记即将支持。设置展示原有真实核心和 SQLite 健康信息。尚未实现来源采集、模型推理、真实事项持久化及完整状态机，不能据此把相关需求标为完成。

## 紧凑间距调整

布局间距采用 4px 基础网格，主要使用 4、8、12、16、24、32px。页头、筛选栏、列表和详情正文统一 16px 水平内边距；顶部栏收至 44px，筛选栏和详情工具栏为 40px。事项行最小高度从 107px 收至 88px，上下内边距从 17px 收至 12px，内部文字间距收至 4px。详情分组间距收至 16px，连接页和设置页同步压缩。正文维持 14px，1px 分隔线保留。

## 全界面视觉走查

本轮检查跟进清单、详情概览与来源记录、连接、设置、空态和新增弹窗；宽窗口 1140×780、窄窗口 860×700。

- 补齐设置菜单选中态与当前页面语义，统一悬停状态；选中边线保留在控件内部。
- 连接、设置标题与主页面保持 16px 左对齐，去掉重复眉题；正文区域最大宽度 768px，避免状态和值相距过远。
- 连接入口使用 Phosphor 图标代替字母/汉字占位；说明与状态采用清晰的主次层级。
- 设置数据逐行对齐，数值右对齐，增加轻分隔线。
- 事项元信息由 11px 提高至 12px，标题和摘要采用固定行高；详情标题、标签、操作区统一对齐，并允许窄窗口换行。
- 空态图标居中，缩小标题与说明间距；搜索快捷键标记、弹窗宽度和提示条间距统一。
- 截图在动画结束状态采集，避免把过渡中的半透明弹窗误判为最终样式。
