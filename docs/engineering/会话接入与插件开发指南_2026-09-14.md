本批将两种本地会话接入修复和来源插件开发资料放在同一个 MR。

- L05：兼容缺失/null ordinal 的 Codex 消息，以受信任行字节位置标识；合法旧 ordinal ID 不变。normalizer v2 重扫旧游标，补回原先跳过的记录。

- P07：新增 [开发指南](../plugins/README.md)、[独立 Schema](../plugins/source-manifest.schema.json)、[格式兼容说明](../plugins/session-formats.md)、可安装的嵌套字段 JSONL 示例，以及 `scripts/check-source-plugin.mjs` 本地校验命令。插件桌面测试使用指南原样文件，验证试运行不写库、启用后收录并产生一条候选、停用/卸载保留历史。

验证：相关 126 项单元测试、类型检查、包边界检查、构建以及会话导入/通用文件导入/插件管理 3 个受影响桌面用例。未重跑本地全量 E2E；远端保留原有必需 CI。

边界：只读追加式受支持格式，不承诺任意日志重写/轮转无损；无法识别的新格式会提示处理。测试文本全部虚构，未读取个人历史；真实客户端授权样本和独立第三方开发者体验仍需验收，不因单测通过把这两项人工验证视为已完成。事项模型语义、截止时间理解和 Kimi 接入不属于本批。
