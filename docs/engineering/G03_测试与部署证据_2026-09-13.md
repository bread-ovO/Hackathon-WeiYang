# G03 测试与部署证据

## 证据分层

- **代码质量**：`pnpm check:boundaries` 与 `pnpm typecheck` 验证包边界和 TypeScript 编译。
- **行为测试**：`pnpm test` 运行 Vitest 单元与集成测试；结果只证明测试覆盖到的行为。
- **构建证据**：`pnpm build` 验证 Electron 可构建；`pnpm package:dir` 生成本地未签名目录。
- **运行证据**：`pnpm test:storage` 和 `pnpm test:desktop` 分别验证 SQLite 与桌面端行为。
- **发布证据**：GitHub Actions 的 `verify` 检查是远端环境证据，PR 合入前必须确认状态为 success。

## 记录规则

每个 PR 描述必须列出实际运行的命令及结果。未运行的命令标为未验证；本地通过不替代远端 CI，构建通过也不代表已签名发布。
