# 默认 Hiyori 打包

用户指定桃濑日和（Hiyori）为默认角色。`package:dir`、`package:dmg`、`package:real`、`package:demo` 以及直接调用项目的 electron-builder 都经过同一对 beforePack/afterPack 钩子。没有无角色打包选项。

```bash
node scripts/fetch-pet-sdk.mjs
pnpm package:dir
# macOS 磁盘映像
pnpm package:dmg
```

构建输入来自固定哈希的 Cubism SDK for Web 5-r.5 归档。`default-model-assets.json` 固定 Hiyori 模型、贴图、动作及 SDK LICENSE/NOTICE 的大小与 SHA-256；`runtime-assets.json` 固定运行库与其许可文件。打包器只写入清单列出的资源，不复制其他模型或任意 SDK 文件。缺失、变更或读取失败使打包退出，不沿用上次的 Haru 或输出没有模型的包。

beforePack 清除旧资源并准备完整默认模型；afterPack 再对实际 app.asar.unpacked 资源逐项校验，并拒绝残留 Haru。纯开发 build 仍清理旧资源，避免调试意外触发初始化；后续打包钩子会重新放入 Hiyori。

首次启动沿用受控模型导入和哈希匹配运行库安装，自动选中并显示 Hiyori。保留已有 `bundled-pet-v1.json` 标记，不覆盖旧用户的模型库、不复活用户已移除的默认角色；以前安装过 Haru 的用户可以在设置移除 Haru、手动导入 Hiyori。打包必含默认模型与用户是否显示桌宠是独立行为。

`bundle-demo-pet.mjs` 保留为兼容的开发验证入口，现在准备 Hiyori；正式包不依赖手动执行此脚本。源码只提交校验清单，不提交 Live2D 二进制。保留模型与 SDK 署名及原始许可；历史正式发布范围由既有许可记录追踪。
