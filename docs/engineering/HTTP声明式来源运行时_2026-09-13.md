# P02 / P03：HTTPS JSON 声明式来源运行时

新增可执行的 HTTPS JSON 读取器和受限网络传输，与已有 local-jsonl 读取器输出同一 SourceEvent。当前为宿主模块，尚未接入插件安装、持久授权/凭据库、HTTP 连接界面或后台消费器；不会仅因模块测试通过就将这些完整需求标完成。

```mermaid
flowchart LR
  Manifest[严格 manifest 校验] --> Grant[宿主提供来源、授权域名与凭据槽]
  Grant --> Reader[分页读取器]
  Reader --> DNS[全部 DNS 地址校验]
  DNS --> TLS[绑定已验证 IP，保留域名 TLS 校验]
  TLS --> Limit[响应类型、字节、超时与取消]
  Limit --> Map[严格 UTF-8 / JSON / 自有属性映射]
  Map --> Event[SourceEvent 校验]
  Event --> Batch[完整批次与续读游标]
  Batch --> Host[调用方事务持久化成功后确认游标]
```

## API 与权限

`createHttpJsonReader({manifest, authorization, transport?, now?}).read({cursor?, signal?})` 返回 `events / cursor / done / pagesRead`。authorization 由可信宿主提供 `sourceInstanceId / domain`，可附 `credential:{id,token}`；域名和槽位必须与 manifest 完全对应。模块不会查环境变量或其他来源的凭据。传输及时间注入仅供可信宿主或测试使用，不能开放给插件或 renderer。

默认传输 `requestHttpsJson` 使用 Node HTTPS GET，明确 User-Agent 和 JSON Accept，保持 TLS 证书校验与 SNI。URL 必须为授权域名的 HTTPS 443，不允许用户信息、片段、authority 编码或歧义反斜杠。manifest 禁止静态查询串，分页参数仅由宿主用 URLSearchParams 编码。

所有 DNS 结果必须满足保守公网地址规则；混有私网地址也拒绝。建立连接时 lookup 固定使用已验证 IP，不再次解析；不使用环境代理或连接池。所有重定向拒绝，不转发 Bearer。拒绝压缩响应，实际字节与 Content-Length 都有限制；内容类型必须为 JSON。总请求超时含 DNS，取消、失败或超限销毁请求/响应，迟到 DNS 不发起连接。错误码不携带 URL、正文或凭据。

IPv4 拒绝内网、环回、链路本地、共享地址、基准/文档、多播等；IPv6 保守限定普通 2000::/3，并排除协议、过渡与文档范围。地址分类无法防止设备路由/VPN劫持；本地 fake-IP 代理的解析结果可能被拒绝，不能把放开非公网段当作兼容修复。

## 分页、限额与取消

每次 read 最多 manifest 声明的 maxPages 页，每页最多声明字节数（协议上限 2 MiB），单请求 15 秒。每批最多 min(maxRecordsPerRun,500) 条事件及 4 MiB 文本字符，与存储批次能力对齐。

完整页先全部解析、映射并校验，再推进游标。第一页面超限直接报错；后续页面装不下当前批次时，返回此前完整页和该页的请求游标，下次重新读取该页，不丢记录。坏页、网络失败或取消不返回部分事件供提前确认。调用方必须在事务持久化成功后才保存返回游标。

游标绑定 manifest、来源和授权域名；下一页值只作为参数值，不能跳转为任意 URL。跨次 read 保存请求游标摘要以检测循环，最多 128 页，超过明确失败。到达 done 后用该游标读取不重复请求；新一轮轮询需不传旧游标，并依靠事件修订去重。游标是宿主保存的状态，不是可发给不可信插件的授权令牌。

每个 reader 实例共享一分钟滑动请求额度并拒绝并发 read。额度不足时不长时间等待：已有完整页则返回可续进度，否则报 RATE_LIMITED。宿主应为同一授权保留单实例，不能反复新建实例绕过速率；进程重启后的持久速率预算仍属于后续宿主集成。

## 验证与公开源探针

本机 `pnpm check` 通过：462 项单元、6 组 SQLite 集成、5 项桌面测试。新增测试涵盖域名/凭据边界、DNS 绑定、实际流字节、取消和迟到结果、循环分页、额度续读、UTF-8/JSON 错误及 JSONL/HTTP 形状差异下的事件一致性。网络传输单测使用可控 DNS/HTTPS 流替身，不能冒充公网实测。

`node scripts/probe-http-source.mjs` 使用 [公开 manifest](../../examples/sources/github-release-assets.json) 请求固定仓库的公开发布资源元数据，只输出数量，不传 token、不下载资源、不写数据库。接口来源见 [GitHub Releases 文档](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)。它不是完整 GitHub 事项连接器，发布资源不代表业务事项已完成。

本机探针结果为 HTTP_ADDRESS_DENIED：api.github.com 被系统解析到 198.18.0.75，规则按设计拒绝。独立 CI Public HTTP source probe 会保存实际探针日志；该步骤为外部可用性诊断，不阻断常规构建。必须看探针步骤及日志，不能仅用绿色 workflow 断言公网验证成功。
