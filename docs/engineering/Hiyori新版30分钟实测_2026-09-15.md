# Hiyori 新版 30 分钟实测（PET14）

本轮在 Apple M4 / 16 GiB / macOS 上，以当前 Hiyori 和 balanced 性能档实际运行 **1800.022 秒**，31 个时间点采样、5 次 WebGL context loss/restore，预先设定的工作集与 V8 堆趋势检查通过。没有使用 Haru，也没有用虚拟时钟缩短长测。

[原始采样与阈值](../evals/results/ten-closeout-2026-09-15/hiyori-soak.json)记录系统、运行时版本、模型资源规格与 SHA-256；[默认资源一致性核对](../evals/results/ten-closeout-2026-09-15/hiyori-default-pins.json)将所测模型与当前 default-model-assets.json 的 18 个渲染资源逐项比较，全部一致（LICENSE/NOTICE 文档不计入渲染资源），避免用另一套 Hiyori 资源冒充默认模型。

| 指标 | 预热后的基线中位数 | 最后 5 点中位数 | 变化 |
| --- | ---: | ---: | ---: |
| Browser 工作集 | 160.50 MiB | 158.05 MiB | -2.45 MiB |
| GPU 进程工作集 | 118.42 MiB | 115.47 MiB | -2.95 MiB |
| 桌宠 renderer 工作集 | 149.28 MiB | 166.16 MiB | +16.88 MiB |
| V8 已用堆 | 24.60 MiB | 26.73 MiB | +2.13 MiB |

不是“内存完全不增长”：renderer 工作集和堆有增加，但小于事先固定的绝对/相对增长上限，且未同时满足回归斜率与连续显著上升窗口规则。三个观测进程均未重启。工作集不是严格跨平台 RSS；GPU 进程内存不是显存。

同批[生命周期测试](../evals/results/ten-closeout-2026-09-15/hiyori-lifecycle.json)测得闲置 **29.98 FPS**、互动 **55.88 FPS**，WebGL 恢复和强制崩溃后的主窗口存活/桌宠重新打开均通过。当前档位为闲置目标 30、互动目标 60 FPS，承接此前顺滑度优化；旧表内 15/30 FPS 是早期档位，不再用旧 Haru 报告替代本版证据。

CPU 为 Electron 进程采样值，仅作资源观察，不等同电池能耗或系统功耗。同期有本机其他工作；结果仅适用于记录的设备、模型和 30 分钟窗口，不推断 Windows/Linux、所有屏幕或长期零泄漏。跨平台矩阵和正式模型授权验收仍由对应需求承担。

执行：

```sh
PET_SOAK_MINUTES=30 PET_SOAK_ARTIFACT=/private/tmp/hiyori-soak.json pnpm test:desktop tests/desktop/pet-soak.spec.ts
pnpm test:desktop tests/desktop/pet-render-lifecycle.spec.ts
```

本轮夹具选择本地 SDK 目录时使用真实路径，兼容 worktree 的本地 SDK 符号链接；产品的路径授权与防越界规则没有放宽。
