Framework 固定版本许可见[官方 5-r.5 LICENSE](https://raw.githubusercontent.com/Live2D/CubismWebFramework/5-r.5/LICENSE.md)。Core 条件见[专有软件许可](https://www.live2d.com/eula/live2d-proprietary-software-license-agreement_en.html)。本次实际 ZIP 的 `Core/RedistributableFiles.txt` 列出 `live2dcubismcore.d.ts`、`live2dcubismcore.js`、`live2dcubismcore.min.js`，是否分发仍需满足协议的其他条件。

开发与发布的区别见[官方 SDK 发布许可](https://www.live2d.com/en/sdk/license/)。可扩展应用的定义、审核和发布条件见[Expandable Application](https://www.live2d.com/en/sdk/license/expandable/)；本项目具备任意模型导入能力，因此需要在该类别上确认，当前不是已获豁免的结论。

Haru 对应的规则见[素材协议](https://www.live2d.com/eula/live2d-free-material-license-agreement_en.html)和[样例模型条款](https://www.live2d.com/en/learn/sample/model-terms/)。本地验证页标示 `© Live2D Inc.`；样例角色不会随本次 PR 或打包产物公开。
