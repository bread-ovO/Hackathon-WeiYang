# 预置来源与本机演示桌宠

本轮补齐安装后开始体验的入口。插件多信源仍是产品主体，桌宠为附加入口。

## 预置来源

连接页优先展示飞书、GitHub、本地 JSONL 三个内置连接卡片。点击配置直达对应表单，用户无需先安装插件或编写 JSON。私有来源仍需指定项目、读取范围及凭据。自定义声明式插件入口继续保留。

“一键体验”无需账号或文件选择器：宿主生成固定的三条虚构记录，建立独立的“不咕上手体验（虚构数据）”项目，经既有插件检查、样例试运行、激活、同步链路写入记录。既有后台规则生成两条待确认候选，第三条假设语句不建事项。展示真实候选、原文和人工收录流程，不借用设计预览中的多源自动匹配结果。

示例内容只有在用户点击一键体验后才写入数据库；不读取个人目录、不请求网络、不使用凭据。重复点击已启用的体验插件不重复创建项目或插件；停止或卸载沿用已有生命周期，历史保留。此处不提供清空个人数据或自动开启已暂停后台整理的捷径。

## Haru 本机演示版

按用户选择，本机演示先用 Haru，正式默认 Live2D 角色后补。Haru 为 Live2D 样例，设置页显示 `Haru © Live2D Inc.`，不作为 BUGU 原创角色宣传。

```sh
# 已准备固定版本运行库时，直接构建本机演示版
pnpm package:demo
```

演示版输出到 `release/demo/mac-arm64/BUGU 不咕.app`，与普通输出分开。只从被 Git 忽略的 `.pet-sdk` 复制资源，校验当前运行库哈希，保留 SDK LICENSE 和 NOTICE。缺资源或哈希不匹配会导致打包失败，不在用户第一次启动时联网下载。

新用户目录首次启动自动安装受控运行库、导入并选中 Haru、显示真实 Live2D 窗口。初始化只执行一次；用户移除或取消选择后，重启不会再次强制恢复。已有模型库不切换当前模型；缺失运行库时可由演示包补齐。初始化错误不阻止主工作区启动，可以在设置中处理。

普通 `pnpm build` / `pnpm package:dir` 会清除上一次演示构建的资源，避免样例素材混入普通包。正式默认模型及正式发布权限继续按既有许可边界跟踪，本机演示构建不代表这些事项已经完成。

## 验证

- 新增来源入口端到端验证：无文件选择器完成采集、生成两条候选，重启后重复体验不新增项目或事项。
- 新增 Haru 首次启动验证：无需手动导入即进入真实渲染状态，帧数增长；移除后重启不复活模型。
- 单元验证：初始化一次性、已有模型选择保护、普通构建无素材时不执行导入；IPC 禁止携带任意路径，安装期间拒绝竞争操作。
- 复查既有插件生命周期、飞书/GitHub 配置及 IPC 页面边界。
