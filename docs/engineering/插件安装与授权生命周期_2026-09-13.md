# P04 插件安装与授权生命周期

连接页现支持安装声明式 Source manifest JSON：选择插件 → 查看读取范围与当前版本权限 → 选择项目和匹配域名的来源凭据 → 原生选择目录（本地来源） → 样例试运行 → 原子启用。只执行既有 local-jsonl / HTTPS JSON 模板，不加载代码、解压 ZIP 或下载依赖。

试运行仅返回样例数量，不写正式事件。确认令牌由宿主保存，绑定 manifest 摘要、项目、实际文件或精确域名与凭据引用，10 分钟过期；失败、取消、替换插件或停用会使旧确认失效。启用在 SQLite 事务中保存完整版本与授权，同 ID 同版本不同摘要拒绝覆盖；失败保留旧版本。

## 权限执行

安装文件限制 128 KiB，严格 UTF-8、manifest/API 版本校验；拒绝符号链接、非普通文件和读取时替换。安装确认传输还有 64 KiB JSON 限制。摘要对规范化 manifest 计算，格式变化不改变内容身份。

本地来源只读取用户所选目录中 manifest 指定的精确文件，拒绝越界与符号链接，不遍历目录。HTTPS 来源通过既有 TLS/DNS 公网验证与固定地址传输，不跟随重定向；凭据在发送前由宿主按域名和 source 用途解密，界面及核心数据库只持有引用。运行中的请求在停用和凭据删除时取消；取消后不提交。

## 运行与恢复

宿主每 30 秒检查已启用来源，遵循 manifest 的采样间隔；可手动同步，尚未到采样时间时拒绝额外运行。同域名请求额度跨读取器、试运行与升级共享。请求失败显示异常暂停，需要重新试运行启用。运行时额度保存在内存，应用重启会重置窗口；这不替代服务端配额管理。

事件、作业、项目关系和游标统一事务提交，检查授权版本与旧游标 CAS。停用使旧授权失效；卸载只删除安装关系的可见性，保留历史事件。重装生成新的来源 UUID，永久保留旧来源归属，防止历史来源绕过权限入口。SQLite 显式迁移至 v6。

HTTP 完成一次分页扫描后，下个采样周期开始新的有界扫描，按 externalId/revision 去重；本地 JSONL 从文件游标续读。文件改变、无效事件或不匹配的同修订内容不会静默覆盖历史。

## 验证与剩余范围

本机使用隔离虚构数据验证安装、只读试运行、启用/同步、重启、停用、卸载保留历史；单元与数据库集成覆盖升级回滚、令牌过期/并发替换、在途取消、授权代际、域名用途隔离、限额和游标恢复。真实公网 HTTPS 传输已有第六批 CI 探针；本批安装链路的 HTTP 请求使用受控测试传输，未拿个人凭据或真实聊天验收。

界面展示事件接收进度，不意味着模型已经提取或核验事项。飞书/GitHub 专用授权 UI、通用连接轮询器的取消问题、历史删除、安装包签名及跨平台验证仍由各自需求推进。
