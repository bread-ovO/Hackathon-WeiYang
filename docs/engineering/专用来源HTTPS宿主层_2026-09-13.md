# 第十批：专用来源 HTTPS 宿主层

新增共享 `requestHttpsResponse`，返回受限状态、白名单响应头和响应字节。原 `requestHttpsJson` 通过同一实现继续保持成功 JSON 字节接口，现有声明式插件不需迁移。

继续沿用公网 DNS 校验与地址固定、TLS 证书检查、拒绝重定向、取消和容量限制。请求头仅允许 Accept、If-None-Match、If-Modified-Since、X-GitHub-Api-Version，不能覆盖 Host 或 Authorization；在异步 DNS 前复制并校验大小写重复、控制字符和长度。

响应仅投影 etag、link、retry-after、x-ratelimit-reset、x-ratelimit-remaining、last-modified、content-type。304 必须没有实际正文，其 Content-Length 可以描述缓存实体大小；403/429 的正文仍有界读取，但宿主不会将其传给适配器。

## 主进程接线模块

`createSourceHttpTransport` 将共享响应适配到飞书/GitHub 接口，固定允许域名、15 秒超时和 8 MiB 上限。成功响应严格解码 UTF-8 与 JSON；304/403/429 返回安全状态与头，正文为 null。错误仅为固定代码。

`createProviderSourceReader` 把选定来源、仓库/会话范围与保险库引用绑定起来。适配器只持有占位值，实际发送前由主进程重新按域名及 source 用途读取凭据。每次条件请求也重新解析引用，已移除的凭据不会因缓存继续被使用。返回事件重新绑定已授权来源 ID，并通过标准事件校验。

这两个模块已能组合运行，仍需专用连接配置 UI、持久授权/游标、调度器及撤回证据事务接入。不能将本批模块验收等同于 F03/G02/G04 整体完成。

## 验证

本机完整检查：833 单元、7 组 SQLite、7 桌面通过。包括旧 64 个 HTTPS 回归、新响应 31 项、宿主 38 项、三层组合 14 项、凭据绑定 4 项。组合测试只模拟 DNS/HTTPS 底层，真实运行适配器、宿主和共享响应实现；曾发现并修复 body/bytes 接口错位。

公开探针读取固定 GitHub release 元数据，额外请求 ETag→304，输出状态与计数，不使用个人凭据、不下载资产、不写数据库。本机网络地址校验拒绝外网探针；真实公网结果以 CI 对应 probe step 日志为准，不能以工作流整体绿色替代非阻断探针结果。
