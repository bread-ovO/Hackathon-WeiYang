## 2. SDK Release License 公开分发条件（发布前必须完成）

依据 Live2D SDK 发布许可（https://www.live2d.com/en/sdk/license/）：

- [ ] 确认主体适用版本（个人/小规模事业者条款或商业许可），按团队实际营收规模选择
- [ ] 在应用内或发布材料中按官方要求标注 Live2D Cubism SDK 使用声明
- [ ] 确认 Core 再分发方式符合条款（当前按 RedistributableFiles.txt 原样分发 min.js）
- [ ] 若分发给第三方，确认第三方条款传递要求

以上未完成前，README 与对外材料不得声称「可公开分发」。
