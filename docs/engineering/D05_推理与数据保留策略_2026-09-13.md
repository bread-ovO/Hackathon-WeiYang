# D05 推理与数据保留策略

2026-09-14 更新：事项分析采用用户配置的 OpenAI 兼容 API 或本机已登录 CLI；默认不启用模型调用。原始会话、事项、证据和条件历史保存在用户本机 SQLite；导出由用户主动触发。云推理关闭时不发送原文，启用时仅发送完成推理所需的最小上下文，并保留来源引用而非复制无关历史。

删除授权来源后停止后续同步，删除项目时同步清理其派生索引、作业和通知记录；数据清理由显式用户操作触发。应用不把个人凭据、原文或数据库提交到仓库。

CLI 复用该工具自己的登录，不读取或复制 OAuth 令牌。CLI 通常仍调用远端模型，不等于本地推理。配置修改、关闭授权或应用退出会取消进行中的调用。
