# 第三批：条件编辑、截止时间与分页

2026-09-13，基于已合入 PR #5。对应 H01、U01、V01、P01。

## 真实工作区

- 截止时间以本机时区输入、UTC Z 持久化，可清除；Schema、存储和数据库约束拒绝非法日期。拒绝本地时间解析后静默归一到另一时刻。
- 条件可新增、修改、删除，保存产生新版本，历史版本只读；保留原条件的事件引用，数据库再次检查项目归属。旧证据保留在原条件版本，新版本证据状态回到 unknown。
- 手动收录、忽略和恢复收录可操作，保留人工决定和版本；重复自动输入的抑制仍需后续流水线接入。
- 项目、业务状态、收录状态、归档和文本筛选在 SQL LIMIT 前执行；keyset 游标绑定筛选条件，默认每页 50 条、单次上限 100，可继续加载。列表独立 FTS 包含归档/忽略/未分配事项，不与候选召回索引混淆。
- 列表返回总匹配数和全局活跃数，不以当前页大小冒充全部事项数。读取代次隔离过时结果；保存期间锁定筛选并按最新筛选重新读取。

## 插件契约

P01 使用 JSON Schema/Ajv 及派生类型，支持 http-json 和 local-jsonl 声明、稳定宿主 API 版本区间、有限 JSON Pointer 字段映射、目录/凭据授权槽位。提供两个完整合法样例；拒绝缺字段、非法版本、任意代码字段及权限不一致。协议通过不授予任何读取权限。P02–P06 的运行时、安装、授权及恢复仍未实现。

## 剩余范围

来源/活跃度筛选仍依赖真实采集；条件自动提取和模型重评估、自动重放对人工选择的保护、人工撤销、插件运行时尚未接通。既有收录/归档/业务状态的独立语义保留，不因本次新增编辑能力宣称完整事项自动闭环完成。
