# BUGU 桌宠表情动作与气泡

本批接通 PET06 的表情动作和 PET09 的文字气泡。显示桌宠后，设置页可选择模型提供的动作或表情并播放，也可输入一句话显示气泡。气泡可联动当前所选动作；这些入口是手动预览，主动调度和免打扰仍由 PET10、PET11 接入。

## 动作与运行库

动作清单从受控模型入口读取，只向主工作区提供标签和索引 ID。播放请求不接受资源路径，必须命中当前模型清单。每类最多 64 项；无可选动作或目录解析失败时保留基础渲染。

真实 Cubism 单次动作结束后恢复 Idle；预览最长 30 秒，表达式展示 3 秒后回到默认参数和待机。模型没有 Idle 时只驱动已有的呼吸与眨眼参数。缺少或损坏的可选动作返回不可用并恢复待机，不销毁整个角色。异步加载按代次取消，切换模型释放原窗口及资源。

SDK 仍为固定官方 Cubism 5-r.5 包，新增官方表达式模块导出；运行库安装版本更新为 `cubism-web-5-r.5-actions1`。升级后需重新执行 `node scripts/fetch-pet-sdk.mjs`，在设置中重新选择 `.pet-sdk/runtime`。仅 Framework 构建产物的大小和哈希发生变化，Core、shader 与许可证文件继续按原清单校验。

动作目录解析通过独立纯函数子路径导出，桌宠 renderer 不加载完整 Ajv 校验器，不放宽 CSP。运行库与模型不进入仓库或安装包，发布许可仍由 PET15 跟踪。

## 气泡与队列

主进程队列最多 8 项（含当前项），一次只交付一项，绑定模型及窗口代次。当前项使用随机 ID，renderer 完成、关闭或报告不可用后确认；伪造 ID、其他窗口与子 frame 无法确认。隐藏、切换、移除模型或窗口故障时清空队列。

文字最多 240 字符，允许正常换行，拒绝其他控制字符。使用 `textContent` 展示，不解析 HTML。气泡默认 12 秒关闭，也可直接关闭；联动动作结束后才确认该项，下一项不与其叠加。重复轮询不会重播已接收的动作。

气泡字体固定 14px，在最小 50% 角色窗口内也保持可读；长文换行并在气泡内部滚动。关闭按钮始终位于气泡内。气泡矩形参与命中，字符区之外仍保持既有穿透策略；显示气泡不会调用窗口激活或焦点 API。

## 验收证据与剩余范围

本机 macOS arm64、Electron 44.3.0，使用官方 Haru 验证：TapBody 动作、真实表达式及返回 Idle；表达式与文字联动；气泡出现不改变主窗口焦点；HTML 外观文字保持纯文本；队列逐项关闭、12 秒消失及隐藏后清空；最小窗口内长文可滚动且不越界。移除可选动作/表情后，模型仍渲染、更新帧并展示气泡。

单元测试覆盖清单顺序、容量、索引 ID、无路径输出、非法参数、队列绑定、失效确认、重复轮询、取消与晚到结果。没有 SDK 的 CI 会跳过真实模型用例；本机实际模型与系统鼠标测试单独执行，不把跳过视为通过。

自动说话、冷却和每日上限、静默时段、锁屏/演示抑制尚未接入。长时性能与真实多屏设备、Windows 验收继续由 PET14、PET16 跟踪。

最终整体验证：`PET_OS_POINTER_TEST=1 pnpm check` 通过 985 项单测、7 组 SQLite 测试和 16 项桌面测试。复审补充了模型选择/移除与旧状态请求并发的版本保护，控制器 9 项回归和 TypeScript 检查通过；随后 5 项实际模型管理、展示回归及 `pnpm package:dir` 均通过。

展示请求提交队列后，直接返回主进程已验证的模型快照和实时展示状态，不让后续模型列表读取失败反转已成功的提交。模型变更成功后更新快照版本，旧读取不能覆盖新选择或已删除模型的列表。
