# BUGU 桌宠拖动与透明区穿透

本批接通 PET07、PET08 的 macOS 桌面交互。用户可拖动角色、选择 50%–200% 的大小、按需置顶、开启或关闭透明区穿透，并在主窗口重置位置或隐藏桌宠。偏好和位置保存在本机；重启仍默认隐藏，显示时恢复位置。

## 交互与实现

主工作区通过严格契约提交大小、置顶和穿透偏好，不接受窗口 ID 或任意坐标。独立桌宠仅能提交命中布尔值以及拖动开始、移动、结束；主进程根据系统鼠标位置计算位移，并限制到可用屏幕区域。参数、发送窗口、主 frame 和页面 URL 均校验。

每个真实模型帧完成后，最多每 100ms 将帧缓冲缩小到 128×128 命中图，只读取 64KiB 像素。根据可见 alpha 判断角色区域；缓存不向主进程传图，也不截取其他应用。透明区调用 Electron 鼠标穿透并保留移动转发，进入角色后恢复交互；拖动期间持续接收鼠标，结束或隐藏时解除拖动。加载提示仅自身矩形保持可交互。

`pointermove` 用于已捕获的拖动，`mousemove` 用于 Electron 的穿透移动转发。避免 `pointerdown.preventDefault()` 抑制兼容鼠标事件后拖不动。拖动阶段最多每秒 30 次移动请求，结束后保存位置。

偏好采用临时文件原子替换；拒绝超长、非普通文件、符号链接和非有限坐标。初始化时忽略中间位置事件，并在 `showInactive()` 后重新应用受控坐标，避免 macOS 显示时自动偏移。屏幕布局变化后重新限制范围；“找回桌宠”重置到主屏可用区域。

## 实际验收

本机使用官方 Haru 与固定 Cubism 5-r.5 运行库、Electron 44.3.0、macOS arm64 验证。独立临时 profile 测试了缩放、置顶、位置与偏好重启恢复，以及主窗口关闭穿透、隐藏桌宠的入口。外部无权限窗口调用拖动或命中 IPC 被拒绝。

通过 `PET_OS_POINTER_TEST=1` 额外执行真实 CoreGraphics 鼠标事件：透明角点击使下方独立测试窗口计数增加一次，角色内部点击不增加计数；连续真实拖动使桌宠窗口横纵各移动约 50px。没有用 Playwright/CDP 鼠标事件代替系统穿透证据。此测试只检查既有系统权限，不主动申请权限，不读取用户数据。

本轮本机 `PET_OS_POINTER_TEST=1 pnpm check` 通过：954 项单测、7 组 SQLite 检查、15 项桌面测试；设置页以 1440px 和 880px 宽度走查。

普通 CI 不下载 SDK，缺少 SDK 或未显式启用系统事件测试时会跳过相关用例，不能把 CI 绿色等同于完成系统鼠标验收。多屏限制与异常持久数据由单元测试覆盖；真实物理显示器拔插和 Windows 行为仍需要独立设备验证，归入 PET16。

表情动作调度、气泡、免打扰及长时性能验证继续由 PET06、PET09–14 跟踪。本批没有加入自动话语或 TTS。
