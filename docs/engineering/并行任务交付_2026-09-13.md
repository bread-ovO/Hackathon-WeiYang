## E04

`createRequestHandler` 拒绝外来 WebContents、非主 frame、异常页面地址、未知方法、额外位置参数及 schema 越界字段。失效 frame 读取失败时拒绝请求，内部异常不将路径或错误文本回传 renderer。生产 preload 仍只公开 health。

测试覆盖真实 Electron 中同 URL 外来窗口、畸形参数和恶意来源正文转义。生产 CSP 禁止子框架；测试临时放宽 CSP 后，真实子框架仍没有 preload 桥。非主 frame 的身份拒绝另由单测验证，未将“子框架无桥”声称为真实子框架 IPC 调用测试。

## S06

`openStore.search` 提供 `upsert({ projectId, candidateId, title, text, codeIdentifiers })`、`query({ projectId, text, limit? })`、`remove(projectId, candidateId)` 和 `rebuild()`。调用方必须提供已确认的项目归属，不从正文猜测。

迁移保留 v1 事件、游标、作业和事项。投影表保存原文，FTS 为可重建派生数据，写入和重建采用事务。项目过滤发生在 SQL LIMIT 前；默认返回 20 条、最多 100 条，按 candidateId 稳定排序。输入有长度限制，检索词编码后以 AND 组合，不执行用户 FTS 运算符。

中文使用单字/双字组合，英文拆分大小写及代码标识符；这不是语义搜索。测试固定已知漏召回：登入、认证不会匹配登录，receiv 不匹配 receiveEvent。当前没有生产投影调用，因此不会直接改变现有界面搜索行为。

## PET03

`validateModelDirectory(directory, entry, overrides?)` 返回 `ok`、结构化问题、已校验资源清单及读取字节数。入口为目录内相对 `.model3.json`，支持 Version 3 FileReferences 的模型、纹理、动作、表情及辅助 JSON/WAV 引用。拒绝路径越界、URL、符号链接、缺失文件、非法 UTF-8/JSON 和容量超限；重复资源去重。

默认 JSON 1 MiB、256 个文件（含入口）、单文件 32 MiB、总量 128 MiB、纹理单边 8192 和 16M 像素；调用方只能收紧。PNG 校验 CRC、受限解压及行长度，暂仅支持 8-bit 非隔行灰度/RGB/灰度 alpha/RGBA，不支持索引色。MOC3/WAV 只检查头部，辅助 JSON 仅校验编码与对象格式，未做 SDK 语义兼容判断。

预检通过不等于可以渲染，也不是对源目录的持续信任。导入时应在 worker/utilityProcess 中执行 CPU 校验，将资源复制到私有 staging 后重验复制字节，再发布；本模块不保证恶意并发目录替换下的沙箱隔离。目前未引入 SDK 或任何第三方模型资产。
